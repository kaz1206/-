# P1 実機確認: Windows で行う操作

このフォルダは**実機確認専用**です。P1 本体（`src/`、`mql5/`）とは完全に分離されています。
確認項目の分類と記録は [RECORD.md](RECORD.md) にあります。

---

## やることは 4 つだけです（所要: 準備 10 分 ＋ 自動実行 15〜30 分）

| # | あなたが行う操作 | 所要時間 |
|---|---|---|
| 1 | 検証専用の MT5（ポータブル版）を用意し、**デモ口座**でログインして閉じる | 約 10 分 |
| 2 | このリポジトリのファイルを Windows に取得する | 約 2 分 |
| 3 | PowerShell でコマンドを 1 つ実行し、終わるまで待つ（MT5 が何度か自動で開閉します。触らないでください） | 15〜30 分（待つだけ） |
| 4 | できあがった `results_<日時>.zip` を送る | 約 2 分 |

> コンパイルに失敗した場合だけ、追加の操作が 1 つあります（下の「困ったとき」）。

---

## 手順 1: 検証専用のポータブル MT5 を用意する

**普段使っている MT5 とは別のフォルダ**を使います（普段の環境を汚さないため）。

1. 普段の MT5 のインストールフォルダ（例: `C:\Program Files\<ブローカー名> MetaTrader 5`）を、丸ごと **`C:\MT5_verify`** にコピーします。
   - フォルダの中に `terminal64.exe` と `metaeditor64.exe` があることを確認してください。
2. Windows キー + R を押し、次を入力して Enter（ポータブルモードで起動します）:
   ```
   C:\MT5_verify\terminal64.exe /portable
   ```
3. MT5 が開いたら、**デモ口座**でログインします（「ファイル」→「取引口座にログイン」）。
   - **「パスワードを保存」にチェック**を入れてください（自動実行中のログインに必要です）。
   - **リアル口座は使わないでください。** 検証 EA は最小ロットで売買を繰り返します（テスター内のみですが、念のため）。
4. 「気配値表示」に **EURUSD** があることを確認します。
   - 名前が `EURUSD.a` や `EURUSDm` などの場合は、その名前をメモしてください（手順 3 で使います）。
5. 「ファイル」→「終了」で MT5 を閉じます。

## 手順 2: ファイルを取得する

1. GitHub でこのリポジトリを開き、ブランチ **`claude/mt5-ea-robustness-framework-jz17ar`** を選びます。
2. 「Code」→「Download ZIP」でダウンロードし、展開します（例: `C:\work\repo`）。
   - 使うのは `verification\p1\` フォルダだけです。

## 手順 3: コマンドを 1 つ実行する

1. スタートメニューで「PowerShell」を開きます（管理者権限は不要です）。
2. 次をコピーして貼り付け、Enter を押します（パスはご自身の環境に合わせてください）:
   ```
   powershell -ExecutionPolicy Bypass -File "C:\work\repo\verification\p1\scripts\verify_p1.ps1" -TerminalDir "C:\MT5_verify"
   ```
   - 手順 1-4 で EURUSD の名前が違った場合は、末尾に ` -Symbol "EURUSD.a"` のように付け足してください。
   - `-ExecutionPolicy Bypass` はこの 1 回の実行だけに効き、PC の設定は変えません。
3. 終わるまで待ちます。
   - MT5 が自動で開いて閉じる、を 4〜6 回繰り返します。**MT5 の画面には触らないでください。**
   - 初回はティック履歴のダウンロードで時間がかかることがあります。
   - 最後に緑色の文字で `Finished. Please send this file:` と zip のパスが表示されれば完了です。

## 手順 4: 結果を送る

表示された `results_<日時>.zip` を、次のどちらかの方法で送ってください。

- **方法 A（推奨）**: GitHub のブランチ `claude/mt5-ea-robustness-framework-jz17ar` で「Add file」→「Upload files」から、zip を `verification/p1/results/` にアップロードしてコミット
- **方法 B**: このチャットに zip を添付

### 送る前に（任意）

スクリプトは次の情報を自動で伏せ字（`<redacted>` / `<login>`）にしています。
- 口座番号
- 口座名義
- Windows のユーザー名
- PC 名

気になる場合は、zip 内の `summary.json` やログを開いて確認してから送ってください。ブローカー名・サーバ名は、検証に必要なため残しています。

## 困ったとき

| 状況 | 対処 |
|---|---|
| `This MT5 terminal is running` と出た | `C:\MT5_verify` の MT5 を「ファイル」→「終了」で閉じて、もう一度実行してください |
| `Compile did not produce RL_Verify_P1.ex5` と出た | 1. `C:\MT5_verify\metaeditor64.exe` を開く<br>2. `MQL5\Experts\RL_Verify\RL_Verify_P1.mq5` を開いて **F7** を押す<br>3. エラーが出なければ、手順 3 のコマンドの末尾に ` -SkipCompile` を付けて再実行<br>4. エラーが出た場合は、エラー表示のスクリーンショットを送ってください |
| 30 分以上たっても終わらない | そのまま待ってください。1 回の実行は最大 15 分で自動的に打ち切られ、記録されます |
| 途中で止めたい | PowerShell で Ctrl + C を押し、開いている MT5 を閉じてください（途中までの結果でも原因の調査に使えます） |

## このスクリプトが行わないこと

- リアル口座・デモ口座で実際に発注すること（すべて Strategy Tester 内の仮想売買です）
- 普段の MT5（`C:\MT5_verify` 以外）に触れること。例外は、全 MT5 で共有される共通フォルダ（`%APPDATA%\MetaQuotes\Terminal\Common\Files`）で、ここには `RLV_` で始まるファイルだけを作成・削除します
- 設定ファイルにパスワードを書くこと
- インターネットへの送信（結果は手元の zip に保存されるだけです）
