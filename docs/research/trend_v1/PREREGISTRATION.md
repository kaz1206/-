## 1. 目的と仮説

- **目的:** 古典的なトレンドフォロー（移動平均の交差）について、研究基盤の P1〜P10 を正しい手順で通し、ロバストな島が見つかるか、それが別の期間でも通用するかを調べる。あわせて、初心者が基盤の使い方を学ぶ。
- **仮説（H1）:** EURUSD の H4 で、移動平均の交差には P7 のゲートを通る島があり、その代表は P8a（パラメータ固定・別期間）で事前の基準に反証されない。
- **正直な事前の見通し:** 移動平均の交差は誰でも知っている手法で、FX の主要通貨では優位性が薄いと言われている。同じ EA（H1、2022〜2023 年）では P4 の合格が 0 件だった。**0 件で止まるのは十分ありうる結果**であり、その場合も基準は緩めずに失格理由を記録する。

## 7. 結果の読み方（事前に決めておく）

- P4・P7 の合格は「次の段階に進んでよい」という意味で、利益の予測ではない。
- P7 で選ばれても優位性の証拠ではない（優位性がなくても 73% の回で何かが選ばれる）。
- P8a の PASS は「事前の基準に反証されなかった」。`VALIDATION_INSUFFICIENT_EVIDENCE` は「証拠不足」で、優位性がない証明ではない。
- **P10 の合格は「判定の仕組みが偶然を合格させにくい」ことの確認で、この EA が儲かることとは無関係。**
- P9 で安全なロットが出ても、優位性の証拠ではない。

## 8. 既知の限界

1. **P10 の型と EA の違い:** A1 型は「平均線がそろっている間は常に建玉」、この EA は「交差したときだけ建てる」（P10_PLAN の注記）。期間の長さも少し違う（上の表）。P10 の数字は目安として使い、この EA の誤判定率そのものとは扱わない。
2. **テスターのモデル:** OHLC_M1 は実ティックより粗い。スプレッドは 1 分足の履歴の値を使う。P8a の追加コストで一部を補う。OHLC_M1 での最適化は実機で未確認（単一テストは確認済み）。
3. **露出の検出:** 基盤の露出の検査は戦略名と日付で行い、銘柄やワークスペースをまたがない。練習用ワークスペースで見た期間は、この文書で申告して手で避けた。
4. **P6 の補正:** 家族の試行回数に過去の 1,044 試行が入るので、DSR は厳しめに出る（DSR は警告と順位づけにだけ使う）。
5. **事前の確認:** この設定は、偽の端末（模擬 MT5）で P3 → P4 → P5 → P6 → P7 → P8a のロックまで、エラーなく通ることを Linux で確認した（2026-10-12）。模擬の数字は研究結果ではないので記録しない。
